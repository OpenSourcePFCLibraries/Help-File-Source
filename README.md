# PFC Help file (archived)

The PowerBuilder 11 edition of the PFC Object Reference, as a compiled help file (`PBPFC110.chm`, and the WinHelp file `PBPFC110.HLP`) with its source, and as a PDF. The help file and the PDF can be downloaded from the [1.0 release](https://github.com/OpenSourcePFCLibraries/Help-File-Source/releases/tag/1.0).

This content is out of date and is no longer maintained. The PFC documentation is now in the [docs](https://github.com/OpenSourcePFCLibraries/docs) repository, as Markdown kept current with the PFC source:

- [Object Reference](https://github.com/OpenSourcePFCLibraries/docs/blob/main/object-reference/README.md), which replaces this help file
- [User's Guide](https://github.com/OpenSourcePFCLibraries/docs/blob/main/user-guide/README.md)
- [Dialog Help](https://github.com/OpenSourcePFCLibraries/docs/blob/main/dialog-help/README.md), the help of the PFC dialog boxes (`pfcdlg.pdf`)

This repository is archived.
